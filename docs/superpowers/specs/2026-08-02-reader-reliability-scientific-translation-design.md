# 阅读器可靠性与科研翻译增强设计

## 背景

Flutter 版已经能够以原版式渲染 PDF，并在手机和平板上显示点读词卡。真机体验暴露出五项问题：阅读页缺少明确的返回入口；PDF 连续滑动不流畅；词卡内容过少；科研术语经常不在通用词典中；部分具有正常文本层的 PDF 页面无法点读。

用户确认，失败页面在 UPDF 中可以正常选中文字。因此本轮优先修复文本坐标兼容，而不是把这些页面当作扫描件进行 OCR。目标科研方向为计算机、医学、生物和化学。用户接受在本地查询失败时联网，但只允许发送被点击的词或术语及其所在句子，不上传 PDF、整页内容、文档标题或其他文档元数据。

## 目标

- 阅读页始终有清晰、可靠的返回主页入口。
- 长篇、双栏科研 PDF 在手机和平板上能够流畅滚动和缩放。
- 标题、副标题、章节标题和正文中的英文均可点读。
- 单个字符或局部文本坐标异常不再导致整页点读失效。
- 词卡提供适合科研阅读的释义、上下文、例句和来源信息。
- 查询遵循“离线通用词典、离线专业词典、在线翻译”的逐层兜底策略。
- 在线请求遵守最小披露原则，并可被用户关闭。

## 非目标

- 本轮不实现扫描版 PDF 的 OCR。真正没有文本层的文档仍显示明确的 OCR 提示，OCR 作为后续独立功能规划。
- 不承诺像素级复刻 Word；DOCX 继续采用高保真重排。
- 不把第三方服务密钥硬编码进正式安装包。
- 不上传完整 PDF、整页文本、文档名称、作者信息或阅读历史。

## 方案选择

词典能力采用分层混合方案，而不是纯离线或纯在线方案：

1. 优先查询现有离线通用词典。
2. 查询计算机、医学、生物、化学专业词典包。
3. 根据所在句子识别包含点击词的多词术语，并优先查询最长有效术语。
4. 本地仍未命中时，将最小必要文本发送至在线翻译服务。
5. 将成功结果缓存在本机，重复查询无需再次联网。

该方案在离线可用性、科研覆盖率、响应速度和隐私之间取得平衡。

## 导航设计

文档库打开阅读器时使用保留历史的导航操作，不再用阅读路由替换主页路由。阅读页 `AppBar` 左侧始终显示返回按钮：

- 导航栈可返回时执行正常返回。
- 导航栈异常或阅读页由深链接直接打开时，明确导航至主页。
- 返回操作不清除文档、阅读进度、词卡位置或学习记录。

手机和平板使用相同的返回语义，不依赖系统手势作为唯一入口。

## PDF 点读架构

### 当前问题

当前实现会在可见 PDF 页面上为每个单词、每个矩形片段创建 `Positioned`、`Semantics` 和透明绘制组件。科研论文一页可能产生数百个常驻组件，滚动或缩放会反复映射全部矩形并重建组件树。当前单词几何构建还要求整页文本长度与字符坐标数量完全一致；出现局部异常时直接返回空列表，导致整页失去点读能力。

### 新的按需命中模型

PDF 页面仍由 `pdfrx` 渲染，原页面图像、字体、表格和布局不变。点击层改为数据驱动，而不是逐词 Widget 驱动：

- 仅为当前页附近的可见页面异步加载并缓存 `PdfPageText`。
- 页面平时不创建逐词透明控件。
- 用户点击时，将屏幕坐标转换为 PDF 页面坐标。
- 在被点击页面的有效字符矩形中查找命中字符或最近字符。
- 从字符位置向两侧扩展为英文单词；允许撇号、弯引号和词内连字符。
- 对行末连字符进行跨行合并，例如 `context-` 与下一行 `sensitive` 组成 `context-sensitive`。
- 根据句子上下文生成候选二至五词术语，交给术语识别器排序。
- 页面只通过轻量绘制层绘制当前选中范围的高亮，不绘制所有潜在点击区域。

点击命中半径按当前缩放比例换算，保证视觉命中范围稳定，同时避免在两栏之间误选另一栏文字。

### 容错与回退

字符几何采用局部容错：

- 空矩形、非有限坐标和明显越界的字符只在局部被忽略。
- 文本和字符坐标数量不完全一致时，优先按 PDF 文本片段分别校验并建立映射；只跳过不完整片段，不对整页数组做可能导致后续字符错位的简单截断，也不放弃其他有效片段。
- 结构化文本无法建立可靠映射时，回退到 PDF 引擎的原始文本与字符坐标。
- 页面存在文本但某一点击位置没有可靠候选时，不弹出错误词卡；允许用户重新点击。
- 页面完全没有可用文本或字符几何时，显示“该页没有可点读文本”的非阻塞提示。
- 只有文档所有页面均没有文本层时，才维持“需要 OCR”的文档级状态。

### 缓存与重建边界

- 文本与字符几何缓存最多保存当前页附近约 8 页，采用最近使用淘汰。
- 切换文档时立即清空 PDF 页面缓存。
- 翻译状态、词卡拖拽和词卡内容更新不得重建 `PdfViewer`。
- 页面缩放时不重新分词，只在绘制选中高亮时重新映射少量矩形。
- 文本加载和术语识别不得阻塞 Flutter UI 线程中的滚动手势。

### 无障碍

不再为每个单词创建常驻语义组件。PDF 页面使用按行或按文本片段聚合的无障碍语义，点读仍通过页面级点击命中完成。返回、发音、关闭、收藏和翻译重试按钮保持至少 48×48dp 的触控面积。

## 术语识别与查询链

### 查询输入

一次查询包含：

- 点击位置对应的单词。
- 该词所在的句子。
- 句中二至五词的候选术语。
- 用户启用的专业领域：计算机、医学、生物、化学。

候选术语按“专业词典精确命中、包含点击词、词数更长、领域匹配度更高”排序。单词仍作为最终兜底，不因术语识别失败而无法查询。

### 本地查询

本地查询顺序为：

1. 通用词典精确词形。
2. 通用词典词形还原。
3. 专业词典多词术语精确命中。
4. 专业词典单词精确命中及同义词命中。

通用词典命中不会提前终止专业多词术语查询。两类本地查询可以并行完成并合并展示，使 `random` 的通用释义不会遮蔽 `random forest` 的计算机领域释义。

专业词典数据必须记录领域、来源、版本和许可信息。只打包允许再分发的数据；授权不明确的数据不得进入安装包。专业词典采用独立数据表或独立只读数据库，不改变现有生词记录的含义。

### 在线兜底

在线翻译通过 `OnlineTranslationGateway` 抽象接入。移动端只调用受控的翻译网关，不包含第三方服务密钥。请求仅包含：

- 选中的单词或最终候选术语。
- 该术语所在的单个句子。
- 目标语言。
- 选定领域标签。

请求不得包含文件、页图、整页文本、文档标题、作者、文件路径、设备标识或阅读历史。服务返回结构化结果，包括术语译文、领域释义、上下文译文、音标或读音提示、例句、来源标识和可缓存版本。

连续点击新词时取消或作废旧请求；较早请求的响应不得覆盖当前词卡。请求具有超时、重试和离线错误映射。正式发布前必须确定受控网关地址、服务端密钥管理、日志脱敏和保留期限。

### 本地缓存

在线结果以规范化术语、句子摘要、目标语言、领域和服务版本作为缓存键。缓存保存结构化结果、获取时间和来源，不保存 PDF 文件或整页内容。重复查询优先命中缓存。后续可增加过期策略，但旧缓存失效不得影响离线通用词典。

## 词卡设计

词卡按以下顺序展示：

1. 单词或完整术语、发音入口。
2. 音标和词性。
3. 通用释义。
4. 专业释义与领域标签。
5. 当前论文原句。
6. 原句中文翻译。
7. 一至两条例句及译文。
8. 数据来源、离线或在线状态、收藏入口。

本地只命中部分内容时先立即显示本地结果，再按需补充在线上下文翻译，不让网络等待阻塞基础释义。没有例句时不显示空白标题。手机词卡内部可滚动；平板侧栏和悬浮卡保持现有模式，内容增长不得挤压或重建 PDF 阅读区。

## 隐私与用户控制

- 在线翻译默认遵循首次使用告知，用户确认后才发送请求。
- 设置页提供“在线翻译”总开关。
- 请求发出前只截取单个句子；超长句以术语为中心截取，最大长度暂定 1000 个 Unicode 字符，最终值由网关契约测试固定。
- 无网络或关闭联网时，词卡明确显示本地结果和不可用原因。
- 允许用户清除在线翻译缓存。
- 日志中不输出原句、服务密钥或完整服务响应。

## 数据与兼容性

新增专业词典和在线缓存不删除、不重建现有文档、生词、短语、阅读进度或词卡偏好。数据库升级必须是向前迁移，并有旧数据保留测试。用户不需要重新导入文档。

## 错误处理

- 返回导航失败：直接回到主页。
- 页面文字尚未加载：短暂显示加载状态，加载完成后可点击。
- 局部坐标异常：忽略局部并继续提供其他文字点读。
- 该页无文本层：显示页面级提示，不中断 PDF 阅读和翻页。
- 本地词典未命中且联网关闭：显示“本地未收录”，保留开启联网或重试入口。
- 在线超时或失败：保留已有本地内容并显示可重试状态。
- 在线响应格式异常：丢弃响应，不写入缓存，不覆盖当前词卡。

## 实施优先级

### P0：阅读可靠性

- 修复返回主页导航。
- 改为按点击位置进行字符命中。
- 移除逐词透明 Widget。
- 增加双栏、跨行连字符和局部异常坐标兼容。

### P1：词卡信息架构

- 展示当前原句。
- 增加上下文译文、例句区域、领域和来源标识。
- 保证手机、平板侧栏和悬浮卡都能独立滚动。

### P2：科研查询能力

- 接入合规的四领域专业词典。
- 实现多词术语识别。
- 实现在线翻译网关、首次告知、开关、取消、超时和本地缓存。

### P3：后续 OCR

- 对真正没有文本层的扫描 PDF 增加按页 OCR。
- OCR 结果继续使用同一点击、查询和词卡模型。

## 验收标准

- 从文档库打开阅读器后，左上角返回按钮始终可见并回到主页。
- 手机与平板上连续滚动长篇双栏论文时，不因透明单词组件大量重建而出现明显卡顿。
- 缩放、滚动和旋转后，点击位置仍对应正确单词。
- 标题、副标题、章节标题和正文中的单词都可点击。
- 撇号词、复合词和行末连字符词能够正确识别。
- 一个或多个字符矩形异常不会使整页点读失效。
- 快速连续点击不同词，最终词卡始终对应最后一次点击。
- 本地命中立即展示；专业词典或在线结果随后补充时不重建 PDF。
- 在线请求不包含 PDF、整页内容、文档标题、作者或文件路径。
- 离线时通用词典、专业词典和已缓存在线结果仍可使用。
- 现有文档、生词、短语、阅读进度和词卡偏好在升级后完整保留。
- Flutter 单元测试、Widget 测试、静态分析和 Android 模拟器集成测试通过，并在用户平板上完成最终体验验收。
