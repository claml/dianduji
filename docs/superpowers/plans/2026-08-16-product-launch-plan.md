# 点读机产品上线规划 (Product Launch Plan)

> 目标：把 Flutter 点读机从"功能完整的工程"推进到"可发布的产品"。
> 本规划列出现状盘点、上线缺口、阶段路线图，以及三个规划中的新功能
> （句子翻译、用户登录、前端优化）的设计概要。

## 1. 现状盘点（2026-08-16）

### 已就绪（可上线能力）

- **核心功能完整**：TXT/PDF/DOCX 导入 + 系统分享导入、点读翻译、生词/短语
  学习与 CSV 导出、阅读进度、夜间/护眼主题、平板/手机适配、无障碍语义。
- **PDF 阅读器**：原版式渲染、点读命中（含断词合并：连字符/Unicode/U+0002）、
  目录导航、页码跳转、缩放记忆。
- **科研翻译**：5 领域专业词典（1065 条）、多词术语识别、分层查询链、
  在线翻译网关（腾讯 TMT）、LLM 词典整理（DeepSeek-V4-Flash）、
  用户手动释义（author 字段已为社区共享预留）。
- **工程质量**：326 项测试、覆盖率 94.4%、性能基准（词典 196µs、千页 PDF
  导入 1.9s、滚动 86-118 FPS）、真机验证（BTK-W00）。
- **发布签名**：Release AAB 可产出（dianduji-release.jks + key.properties），
  缺失签名变量时构建明确报错，不会误用 debug 签名。

## 2. 渠道决策（待用户确认）

- **A. 国内安卓商店**（华为应用市场 / 小米 / 应用宝等）：目标用户在国内
  （华为平板），最现实。要求：软著（可代办或自助申请）、APP 备案
  （2023-08 起新应用须备案）、隐私政策 URL。
- **B. Google Play**：海外用户；开发者账号 $25；不需要软著/备案，但要
  数据安全表单 + 隐私政策。
- **C. 先小范围直装内测**（APK/AAB 直发 + TestFlight 类渠道）：0 门槛，
  收集真实反馈后再上商店。

### 阶段 1：上线就绪（已完成，2026-08-16 交付）

## 4. 新功能设计概要

### 4.1 翻译句子

- **场景**：论文中长句/段落需要整句翻译，点词不够。
- **实现**：
  1. PDF：开启 pdfrx 文本选择（`textSelectionParams` 当前 disabled），
     长按选句 → `ReaderSelection` 扩展为句子级；或简化：双击句子高亮
     整句（复用断词/句子边界逻辑 `_sentenceAt`）。
  2. 重排文档：长按句子 → 整句选中。
  3. 查询链：句子走在线网关（腾讯 TMT 单句翻译，已支持）或 LLM 句子
     翻译（DeepSeek，质量更好）。展示：原文 + 译文 + 逐句对照。
  4. 词卡增加"翻译整句"按钮（当前句原文已在词卡，缺译文入口）。
- **工作量**：2-3 天（选择交互 + 句子翻译通道 + UI）。
- **隐私**：句子翻译请求仅含该句（≤1000 字符），复用现有最小披露开关。

### 4.2 用户登录

- **目的**：云同步（生词/短语/用户词典/进度）+ 为社区释义共享做准备。
- **方案**：
  1. 服务端：网关扩展账号体系（注册/登录/JWT），或独立轻量后端。
  2. 客户端：登录页（手机号/邮箱 + 密码，或第三方登录微信/手机验证码——
     国内商店对社交登录有合规要求，首版建议**账号密码 + 游客模式**）。
  3. 同步：启动时拉取 + 本地改动增量上传（生词/短语/用户词典三张表）；
     冲突策略：按 updatedAt 合并（简单可靠）。
  4. 社区释义（用户提到的后续）：登录后可上传自己的释义，查询时按
     author 展示多释义列表。
- **工作量**：登录+同步 3-5 天；社区释义服务端 3-5 天。
- **建议**：登录先于社区释义；游客模式保证离线可用。

### 4.3 前端优化

- **品牌落地**：图标、启动页、主题色、设置页排版。
- **体验细节**：空状态插画、加载骨架屏、词卡动效、平板详情面板信息密度、
  手势（双击放大/缩小、左滑返回）、字体渲染（中英文混排）。
- **性能**：PDF 打开速度优化（预渲染缓存）、列表虚拟化复查。
- **工作量**：1-2 天/批，可与品牌化合并。

## 5. 推荐执行顺序（等待用户确认渠道后细化）

1. 品牌化 + 版本化 + 隐私政策（0.5-2 天）
2. 网关正式部署（0.5-1 天）
3. Release 冒烟 + 崩溃上报（1 天）
4. 渠道提交（并行等待审核）
5. 句子翻译（v1.1 第一优先，2-3 天）
6. 用户登录 + 云同步（v1.1 第二优先，3-5 天）
7. 前端优化（贯穿）
